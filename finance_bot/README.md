# Finance Bot — учёт расходов и долгов по стратегии «Лавина»

Асинхронный Telegram-бот на `aiogram 3` + `aiosqlite` + `matplotlib`.

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | точка входа, хендлеры команд и FSM-диалог `/add_debt` |
| `database.py` | SQLite: таблицы `expenses` и `debts`, CRUD-функции |
| `debt_engine.py` | сортировка долгов по «Лавине», помесячная симуляция и расчёт экономии от досрочного платежа |
| `chart_engine.py` | PNG с кольцевой диаграммой расходов за текущий месяц |
| `sheets_engine.py` | дублирование транзакций в Google Таблицу (необязательно) |

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN от @BotFather
python bot.py
```

## Команды

- `/start` — приветствие и меню
- `/add_expense 450 Еда обед в кафе` — записать расход (сумма, категория, описание)
- `/stats` — диаграмма расходов за текущий месяц
- `/add_debt` — пошагово: название → сумма → % годовых → мин. платёж → дата конца льготного периода
- `/debts` — долги в порядке приоритета «Лавины», срок и переплата
- `/debts 50000` — то же + экономия на процентах от досрочного платежа 50 000 ₽
- `/del_debt <id>` — удалить долг, `/cancel` — прервать диалог

## Google Таблицы (необязательно)

Каждый расход, записанный через `/add_expense`, дублируется строкой в первую
вкладку таблицы: `Дата | User ID | Тип | Категория | Сумма | Комментарий`
(заголовок создаётся автоматически). Запись идёт в фоне; если Google
недоступен, бот продолжит работать, а ошибка попадёт в лог.

1. https://console.cloud.google.com → создайте проект (или выберите существующий).
2. **APIs & Services → Library**: включите **Google Sheets API** и **Google Drive API**
   (Drive нужен, чтобы находить таблицу по названию).
3. **IAM & Admin → Service Accounts → Create service account**: любое имя, роли не нужны.
4. Откройте созданный аккаунт → **Keys → Add key → Create new key → JSON**.
   Скачанный файл переименуйте в `credentials.json` и положите в папку `finance_bot`.
   Это секретный ключ: не коммитьте его (он уже в `.gitignore`).
5. Создайте Google Таблицу, нажмите **Настройки доступа** и добавьте email
   сервисного аккаунта (вида `name@project.iam.gserviceaccount.com`, есть в
   `credentials.json` в поле `client_email`) с правами **Редактор**.
6. В `.env` укажите точное название таблицы: `GOOGLE_SPREADSHEET_NAME=Finance Bot`.

При старте в логе появится `Google Sheets: запись в таблицу «…» включена`.

## Банковские выписки (Сбер, Альфа-Банк)

Загружает PDF-выписки (с текстовым слоем, не сканы) в новую таблицу `transactions` и считает по ним отчёт.
Ручные траты (`/add_expense`, таблица `expenses`) не меняются и с выписками не смешиваются:
иначе одна и та же покупка попала бы в учёт дважды.

```bash
pip install -r requirements.txt          # добавился pdfplumber
cp statements_config.example.json statements_config.json   # свои телефоны и правила, см. ниже
python import_statements.py statements_data      # папка с PDF; повторный запуск безопасен
python -m statements.report                      # отчёт в консоли; в боте: /report [ГГГГ-ММ-ДД]
python -m unittest discover -s tests -t .        # тесты (на выдуманных данных)
```

- Банк и счёт определяются по содержимому PDF. Каждая выписка сверяется со своей шапкой (остатки, поступления,
  расходы): если итоги не сошлись, файл пропускается (`--force` загрузит его всё равно).
- Перед записью делается копия базы `finance.db.bak-<дата>` (отключается `--no-backup`).
- Повторная загрузка того же файла или выписки за пересекающийся период не создаёт дублей.
- В отчёт попадают: траты за вычетом возвратов, доход, переводы людям и семье (чистые), крупные разовые покупки
  (порог `big_purchase`) отдельно, проценты по кредитке и комиссии. Переводы между своими счетами, служебные
  проводки кредитки Альфы (транши, погашение основного долга) и наличные в траты и доходы не входят.
- Категории: сначала ваши правила `extra_rules`, затем общие по названию магазина, затем по MCC-коду (Альфа)
  и категории банка (Сбер), иначе «Прочее».

**Приватность.** Репозиторий публичный. `statements_data/`, `*.pdf`, `*.csv`, `statements_config.json`, `*.db`
и копии базы лежат в `.gitignore`: выписки и всё личное (номера телефонов, названия заведений) остаются у вас
на компьютере. Не коммитьте их.

`statements_config.json`: `phones` — последние 4 цифры телефона → `own` (ваш счёт в другом банке) или `family`
(переводы семье); `extra_rules` — `[["REGEX", "Категория"], ...]`; `analysis_start` — с какой даты считать
отчёт по умолчанию; `big_purchase` — порог крупной покупки в рублях.

## Как считается экономия

Симуляция идёт помесячно: на остаток начисляются проценты (ставка/12, кроме
долгов в льготном периоде), вносятся минимальные платежи, а остаток месячного
бюджета направляется в долг с наибольшей ставкой. Бюджет постоянен — платёж
закрытого долга перетекает в следующий. Досрочный платёж вносится сразу в долг
с наибольшей ставкой; экономия = разница переплат двух сценариев.

> Бот однопользовательский: данные не разделены по пользователям Telegram.
> Чтобы закрыть доступ посторонним, укажите свой ID в `ALLOWED_USER_IDS`.
